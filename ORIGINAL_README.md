# Резонанс Двора 0.4 — Большой район

Запуск: **Резонанс Двора 0.4.exe**. Python не нужен. Новая версия находится в `D:\питон проекты\Резонанс Двора 0.4`. Предыдущие версии сохранены. Прогресс скопирован из 0.3 и дальше сохраняется отдельно в `saves/profile.json`.

## Открой «Режимы»

Все новые режимы открыты сразу. Перед запуском можно выбрать любую из шести карт и одну из трёх сложностей.

| Режим | Правила |
|---|---|
| Экспедиция | Пять комнат и босс в финале. Между комнатами выбираешь карту и усиление: привал лечит на 30%, рискованный путь даёт больше врагов и +35% монет за итоговую победу. |
| Поганец против тебя | Дуэль с выбранным боссом. Без трёх предварительных волн. У каждого своя вторая фаза. |
| Довези посылку | Тележка едет, пока ты рядом и нет врагов вплотную. Защити её и довези до финиша за 180 секунд. |
| Набег за кристаллами | Переноси не более трёх кристаллов. Постой у тайника слева 1,2 секунды, чтобы сдать их. После девяти доберись до выхода справа и удержись там 4 секунды. От попаданий добыча выпадает. Лимит — 180 секунд. |
| Захват района | Захвати три маяка в любом порядке, стоя внутри. Враги оспаривают захват. Успей за 150 секунд. |
| Последний круг | Продержись 90 секунд внутри сужающейся и движущейся безопасной зоны. Убийства не обязательны. |

Внизу меню режимов доступны прежние сюжетные разломы и полигон всех 11 героев. Бесконечная арена находится на странице сюжетных разломов.

## Шесть карт

- **Заросший парк:** деревья мешают движению, фонтан восстанавливает здоровье.
- **Грузовой вокзал:** ящики служат укрытиями, перед поездом подсвечивается опасная полоса.
- **Нулевой реактор:** электрические разряды чередуются между отмеченными плитами.
- **Берег поганцев:** камни перекрывают движение и снаряды, прилив накрывает нижний край.
- **Ледяной квартал:** движение с инерцией, отмеченные заранее снежные обвалы.
- **Ночной рынок:** прилавки и вспышки огня по краям.

Карты собраны для игры из свободных материалов Kenney. У препятствий есть столкновения, обычные снаряды останавливаются об них. Лучевые способности могут пробивать укрытия.

## Боссы на фото

- **Бугданчик:** веер ядовитых плевков и лужи; во второй фазе больше опасных областей.
- **Иллюша:** рывки мечом по отмеченным линиям; банкай добавляет параллельные разрезы.
- **Артём:** кольца снарядов, приманки и вспышка, от которой надо укрыться в зелёном круге.
- **Егор:** прыжки и удары об землю; во второй фазе тройной обвал.
- **Игорь:** строит уничтожаемые турели и вызывает орбитальный обстрел.

Атаки показывают область поражения заранее. После приёма у босса есть пауза для ответной атаки. В сюжетных миссиях боссы тоже заменены персонажами на фотографиях.

## Награды и управление

Первый успех в каждом новом режиме на каждой сложности: 600 кристаллов. Повтор: 200 / 240 / 280 в зависимости от сложности, плюс монеты, эссенция и опыт. Победы и лучшие времена сохраняются отдельно от сюжета. Выход через паузу прерывает попытку без наград.

WASD / стрелки — движение; мышь + ЛКМ — атака; Пробел — рывок; Q — способность; E — ульта; R — перезарядка винтовки; 1 / 2 / 3 — смена героя; Esc — пауза; F11 — полный экран; M — эффекты и голоса. Между комнатами экспедиции 1 / 2 выбирают маршрут.

Сохранены все 11 боевых стилей, прокачка, гача, реликвии, настройка старых реплик и редкий едит3000. «Купи кирпич» звучит только у торговца. Неопознанные голоса можно назначить вручную в настройках. Ролик можно посмотреть в кинозале или пропустить клавишей Esc при редком появлении после победы.

## Проверка и исходники

Python 3.11: `python -m pip install -r requirements.txt`, затем `python main.py`.

Тесты: `python -m unittest -q test_game test_v2 test_v3 test_v4`.
Проверка экранов и видео: `python main.py --smoke --screenshots work/screenshots`.
Для сборки установи PyInstaller и запусти `Собрать exe.cmd`.
