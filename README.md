# Резонанс Двора — браузерная версия

Порт исходной Python/Pygame-игры для компьютера и сенсорных экранов. Сохранены 11 героев, 6 режимов, 6 карт, 5 боссов, сюжет, полигон, гача, магазин, прокачка, голоса и кинозал. Игра выполняется в браузере через CPython / WebAssembly и pygame-ce (Pygbag), серверная часть не требуется.

## Android 6 и старые интерактивные доски

[Открыть облегчённую версию](https://nichytm.github.io/Rezonans-dvora/legacy/index.html?board=1). Это отдельная реализация на ES5 JavaScript / Canvas 2D без Python, WebAssembly, ES-модулей и внешних CDN. Начальная загрузка страницы и портретов — около 0,5 МБ. Аудио загружается только после включения звука. Основная страница автоматически направляет сюда Android 6 и старше, Chrome младше 90 и браузеры без WebAssembly. Прямой адрес работает независимо от определения браузера.

Доступны 11 героев, 6 карт, арена из трёх волн и шесть режимов с упрощёнными эффектами и боевой логикой. Можно играть одному или двумя разными героями во всех режимах. Управление использует Touch Events и мышь; Pointer Events не нужны. Отпускание касания останавливает соответствующий стик. При потере фокуса бой ставится на паузу. Счёт побед и лучший результат сохраняются отдельно от полной версии. Гача, прокачка и кинозал относятся к полной версии.

Совместимость проверена разбором всех скриптов как ECMAScript 5 и браузерным тестом с удалёнными WebAssembly, fetch, PointerEvent и URLSearchParams, с Android 6 / Chrome 49 User-Agent и запретом внешних запросов. Это не запуск на физическом Android 6; работу конкретной доски нужно подтвердить на ней.

## Полная версия

[Открыть на интерактивной доске](https://nichytm.github.io/Rezonans-dvora/?mode=board). Для одного игрока выберите «Играть на доске», для двух — «Играть вдвоём».

Откройте адрес GitHub Pages этого репозитория и нажмите **«Начать игру»**. Нужен современный браузер с WebAssembly и интернет для первоначальной загрузки среды с `pygame-web.github.io`. На телефоне удобнее горизонтальная ориентация. Safari/iPhone физически не проверялся.

**Интерактивная доска:** нажмите «Играть на доске» при запуске или «Доска» в верхней панели. Один стик управляет движением, прицеливание и атака ближайшего противника происходят автоматически. Крупные кнопки приёмов, смены героя, паузы и полного экрана собраны внизу по центру. Режим сохраняется в браузере; его можно открыть напрямую параметром `?mode=board`. Панель проверяется в Full HD и 4K. Реальная удобная высота зависит от установки доски.

**Вдвоём на доске:** нажмите «Вдвоём», выберите двух разных героев и начните совместную арену. У каждого свой герой, стик, способности, здоровье и энергия. Оба сражаются с общими врагами: три волны и босс. Между волнами выбирается общее усиление. Если один выбыл, второй продолжает; поражение наступает после гибели обоих. Все 11 героев доступны. Совместная арена не выдаёт награды и не меняет прогресс одиночного сюжета. Для одновременного движения обоих игроков нужен мультитач минимум на два касания.

**Телефон:** левый стик — движение; правый — направление и непрерывная атака. Касание центра правого стика атакует ближайшего врага. Отдельные кнопки: приём, ульта, рывок, перезарядка, герои 1–3. На полигоне кнопка «Герой →» перебирает всех героев. Меню, выбор маршрута и усилений работают касанием. Кнопка «Сенсор» позволяет вручную включить стики.

**Компьютер:** WASD / стрелки, мышь + ЛКМ; Пробел — рывок; Q / E — способности; R — перезарядка; 1–3 — герои; Esc — пауза / назад; M — звук. В верхней панели есть пауза и полный экран.

Прогресс автоматически сохраняется в `localStorage` браузера для текущего адреса. Через `?` можно скачать резервную копию JSON. Приватный режим и очистка данных сайта могут удалить прогресс. Сохранения на localhost и GitHub Pages независимы. При потере фокуса бой ставится на паузу. Фото, звук и видео взяты из исходного архива.

## Структура

```text
index.html          готовая точка входа GitHub Pages
compat.js           ES5-проверка совместимости до запуска Python
legacy/             облегчённая версия для Android 6
touch.js, touch.css сенсорные стики, кнопки, хранение и видео
game.tar.gz         подготовленная игра с ресурсами для WebAssembly
media/              видео для HTML5-проигрывателя
game/               читаемые исходники и исходные ресурсы
  main.py           асинхронный цикл браузера и мост управления
  game.py           меню и управление исходной игры
  model.py          герои, экономика и сохранения
  arena_base.py     базовый бой
  battle.py         боевые стили
  modes.py          режимы и задачи
  worlds.py         карты и столкновения
  bosses.py         боссы
  ui.py             отрисовка
  cinema.py         HTML5-видео в браузере / PyAV на компьютере
web/                редактируемый шаблон страницы, JS и CSS
tools/build.py      пересборка статических файлов
ORIGINAL_README.md  описание исходной игры
```

Архив на Google Диске назывался **«Резонанс Двора 0.3.zip»**; внутри исходники и README имеют версию **0.4 «Большой район»**. Windows EXE, кэш Python и пользовательские сохранения не включены в публикацию. Исходные ресурсы сохранены в `game/assets`; при веб-сборке аудио перекодируется в OGG, а старые неиспользуемые звуки и встроенные видео не попадают в архив.

## Локальный запуск готовой веб-версии

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Открытие `index.html` через `file://` не поддерживается.

## Изменить и пересобрать

Python 3.12, FFmpeg в PATH:

```sh
python3 -m pip install -r requirements.txt
python3 tools/build.py
```

Редактируйте Python в `game/`, обрамление страницы в `web/`. Скрипт создаёт временную копию ресурсов, сжимает звук и обновляет готовые файлы в корне. Исходные WAV не изменяются. Для нативного запуска: `cd game && python3 game.py`.

Проверка игровой логики и отрисовки:

```sh
cd game
python3 -m unittest -q test_game test_v2 test_v3 test_v4 test_coop
```

Дополнительная проверка в Chromium с эмуляцией телефона (при запущенном HTTP-сервере):

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tools/browser_check.py http://localhost:8000
python3 tools/browser_board_check.py http://localhost:8000
python3 tools/browser_legacy_check.py http://localhost:8000
```

Проверяются меню касанием, одновременные стики, отпускание атаки, способности, смена героя, пауза, все 36 сочетаний режимов и карт, восстановление прогресса после перезагрузки, видео и поворот экрана.

## GitHub Pages

Settings → Pages → Build and deployment → **Deploy from a branch**, ветка `main`, папка `/ (root)`. В репозитории уже есть `index.html` и `.nojekyll`; Node.js и сборка на сервере не нужны.

## Материалы

Лицензии Kenney и Open Sans находятся в `game/assets/licenses/`, ссылки на источники — в `game/assets/sources*.json`. Права на фотографии, реплики и остальные материалы исходного архива сохраняются у их владельцев. Отдельная лицензия на весь исходный проект в архиве отсутствовала.
